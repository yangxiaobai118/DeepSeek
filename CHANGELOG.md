# Changelog (repository)

This repository hosts several projects on separate branches:

  control plane. Release notes live in [uniproxy/CHANGELOG.md](uniproxy/CHANGELOG.md).
- `plugin/github-integration` — the DeepSeek Harness GitHub integration plugin.

The root `README.md` on this branch describes the branch layout.
